Overview

rme-split is a command-line tool for splitting multichannel WAV recordings from RME TotalMix audio interfaces into separate mono and stereo WAV files.

RME interfaces like the UFX series can record multiple channels simultaneously into a single interleaved WAV file. This tool extracts each channel or stereo pair according to your TotalMix configuration.

Features

  • Channel layout defined in rme-split.conf — edit without touching the script
  • Auto-detects multi-part recordings (just specify the first file)
  • Fast single-pass extraction (~90x realtime speed)
  • Batch processing of entire SD card volumes
  • Preserves 24-bit audio quality
  • Progress indication and error handling

Installation

Prerequisites

This tool requires ffmpeg to be installed on your system:

brew install ffmpeg

Install rme-split

  1. Download or clone the rme-split script to your preferred location
  2. Make it executable: 
    chmod +x /path/to/rme-split
  3. Optionally, add it to your PATH or create a symlink: 
    ln -s /path/to/rme-split /usr/local/bin/rme-split

Usage

rme-split <command> [args]

Options

Option Description
-q, --quiet Suppress progress output
-v, --verbose Show detailed ffmpeg output
--version Show version information

Commands

split

Split a recording into separate tracks. For multi-part recordings, just specify the first file (_00.WAV) - all other parts are detected automatically.

rme-split split <input.wav> <output_dir>

scan

Scan a volume (SD card) for RME recordings and display information about each.

rme-split scan <volume_path>

batch

Process all recordings on a volume automatically. Creates separate folders for each recording.

rme-split batch <volume_path> <output_dir>

info

Display detailed information about a WAV file. Shows total duration and part count for multi-part recordings.

rme-split info <wav_file>

Channel Mapping

Channel routing is defined in rme-split.conf, located next to the script. Edit that file to change channel assignments or output filenames — no script changes needed.

Config file format

# CHANNELS    OUTPUT_NAME
# single number = mono, N-M = stereo pair (0-indexed)

0       01_vox_g
1-2     0203_rec_vox_g
...

Note: Channel order follows the TotalMix armed recording outputs in slot order. Hardware inputs come first, then recording buses. Update rme-split.conf whenever the TotalMix snapshot changes.

Config File

Channel routing is controlled by rme-split.conf in the same directory as the script. When your TotalMix snapshot changes, update this file — no script edits needed.

Format

# CHANNELS    OUTPUT_NAME
# Lines starting with # and blank lines are ignored.
# CHANNELS: single number = mono, N-M = stereo pair (0-indexed)
# OUTPUT_NAME: output filename without .wav (spaces allowed)

0       01_vox_g
1       02_vox_l
2-3     0304_rec_vox_g

Changing the layout

  1. Open rme-split.conf in any text editor
  2. Update channel numbers and/or filenames to match your TotalMix snapshot
  3. Save — the next split will use the new layout automatically
Tip: Run rme-split info <file> to confirm the channel count of a new recording before splitting.

Examples

Split a recording

# Multi-part recording (auto-detects all parts)
rme-split split /Volumes/RME/UFX08_00.WAV ./output

Scan SD card for recordings

rme-split scan /Volumes/RME

# Output:
REC#     PARTS    CHANNELS     DURATION   SIZE
-------- -------- ------------ ---------- ----------
REC08    6        18ch         80m27s     11.2GB

Get recording info

rme-split info /Volumes/RME/UFX08_00.WAV

# Output:
File Information: /Volumes/RME/UFX08_00.WAV
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
Channels:    18
Sample Rate: 48000 Hz
Bit Depth:   24 bit
Parts:       6
Duration:    80m 27.5s (total)

Batch process all recordings

rme-split batch /Volumes/RME ./output

# Creates:
# ./output/REC08/
Tip: Use the batch command to process all recordings on an SD card in one go. Multi-part files are handled automatically.

Troubleshooting

ffmpeg not found

Install ffmpeg using Homebrew:

brew install ffmpeg

Permission denied

Make sure the script is executable:

chmod +x rme-split

Volume not found

Check that the SD card is mounted. On macOS, RME SD cards typically mount at /Volumes/RME

Empty files

Empty WAV files (0 bytes) are automatically skipped during batch processing.

About RME TotalMix Recording

RME audio interfaces with TotalMix FX can record multiple channels directly to an SD card as interleaved multichannel WAV files. This is useful for standalone recording without a computer.

File Naming Convention

RME uses the naming format UFXnn_pp.WAV where:

  • UFX - Fixed prefix for UFX series interfaces
  • nn - Recording number (01-99)
  • pp - Part number (00-99), used when files are split due to FAT32 limits

FAT32 Limitations

SD cards formatted as FAT32 have a 4GB file size limit. For long recordings at 24-bit/48kHz with many channels, files are automatically split into multiple parts (approximately every 10 minutes for 24-channel recordings).
